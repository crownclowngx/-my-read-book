# 第一章速读：扩消费、稳增长、稳预期与结构性改革

刘世锦｜《十五五经济发展的思考》

本文按作者的论证整理，数据沿用书中的时点与口径。文中的增长目标、改革设想和效果测算均来自作者。 [第一章原文](<../第一章 扩消费、稳增长、稳预期与结构性改革/第一章 扩消费、稳增长、稳预期与结构性改革.md>)

## 1. 为什么已经从高速转入中速，还要防止增长降得太快？

中国经历了三十多年约 **10%** 的高速增长，2010年一季度之后开始逐步减速。作者用“历史需求峰值”解释这个转折。工业化和城市化过程中，有一段需求集中释放的时期。过了需求扩张最快的阶段，增速就会下一个台阶。此后中速增长能维持多久，取决于收入和需求的分布，尤其是能持续扩大消费的中等收入群体有多大。

![图1-4 中国经济增长从高速到中速的转型期](<../第一章 扩消费、稳增长、稳预期与结构性改革/img/图1-4.png>)

*图1-4｜看2010年之后的长期趋势，中国经济增速逐步从高速回落到中速。*

日本从约 **9%** 的高速增长转到约 **4%** 的中速增长，维持约二十年，随后降到约 **2%** 的低速增长。日本进入低速阶段时，人均收入已超过3万美元，社保和城乡公共服务也较成熟。中国在作者写作时仍在高收入门槛附近，而这个门槛会逐年上移。作者因此主张，未来五年争取保持 **5%左右** 的增长，把 **4%** 作为应守住的底线。

## 2. 消费缺口有多大？为什么说它是结构性的？

书中图表显示，中国居民实际最终消费占GDP约 **44.5%**，全球约 **63.6%**，相差约19个百分点。作者又按购买力平价与处在相近发展阶段的OECD经济体比较，中国的家庭消费、最终消费和服务消费占比大致只有对方的七成。换了一组参照，差距依然明显。

![图1-5 我国居民实际最终消费占GDP的比重](<../第一章 扩消费、稳增长、稳预期与结构性改革/img/图1-5.png>)

*图1-5｜纵轴是居民实际最终消费占GDP的比重，横轴是人均GDP。*

**① 基本公共服务有缺口。** 吃穿等生存型消费趋于稳定后，新增需求更多来自教育、医疗、住房、养老等发展型消费。这些需求能不能实现，取决于学校、医院、保障房和社保能否覆盖到家庭。书中举的例子是，机关事业单位退休人员、城镇企业退休人员、城乡居民基本养老保险领取者的平均月养老金，分别约为 **6000元、3000元和220元**。家庭能获得多少公共保障，会影响手头有多少钱、又敢花多少钱。

**② 进城工作和在城市安家之间还有距离。** 按正文所用数据，常住人口城镇化率约 **67%**，户籍城镇化率约 **48.3%**。人口集聚能降低供水、办学、就医等服务的人均成本，但一些农民工已在城市工作，子女教育、住房和社保仍难以随家庭一起落地。农村住房在交易和抵押上也受限制，农户把资产转为财产性收入的机会较少。

![图1-6 与中国大致相同发展阶段的各国城市化率](<../第一章 扩消费、稳增长、稳预期与结构性改革/img/图1-6.png>)

*图1-6｜各国取发展阶段相近的年份作比较。图中中国为2023年的约65%，正文采用的数据约为67%。*

**③ 中等收入群体规模偏小。** 按作者采用的划分，中国有 **4亿多** 中等收入人口，还有 **9亿多** 中间偏下及低收入人口。如果有更多家庭进入中等收入群体，改善住房、教育、养老和文娱的需求就能一批接一批释放。中等收入群体规模偏小，现有家庭的需求释放到一定程度后，后续消费就容易接不上。

**④ 国有资本收益较多流向再投资，居民储蓄又集中在高收入群体。** 2022年政府净资产约占社会净财富的 **38%**。在作者的解释里，政府持有的国有股权比重较大，而不少国有企业把利润留在企业继续投资。同期全国储蓄主要来自企业和居民，两者大致各占一半。居民储蓄又更多集中在高收入家庭，而尚有较多消费需求的低收入家庭能动用的存款有限。看储蓄总量之外，还得看钱在谁手里、谁有尚未满足的消费需求。

![图1-7 不同国家政府部门的财富占社会净财富比重](<../第一章 扩消费、稳增长、稳预期与结构性改革/img/图1-7.png>)

*图1-7｜图中比较的是政府部门持有的净财富份额。作者用它引出国有资本收益如何使用的问题。*

## 3. 消费偏低早就存在，为什么现在成了稳增长的难题？

作者说的**终端需求**，包括消费和非生产性投资，后者主要是住房和基础设施建设。过去，消费占比偏低，房地产和基建仍能靠高速扩张撑起终端需求。现在房地产下行、基建减速，消费缺口就显现出来。作者由此把价格低迷、部分产能过剩、债务负担加重等问题，与终端需求不足联系起来。

作者又把增长分成**高度**和**宽度**。技术创新提高生产率，抬升增长的高度。教育、社保和就业机会则决定有多少人能提高收入并形成持续需求，也就是增长的宽度。以武汉的无人驾驶出租车为例，技术可以提高出行效率，但如果部分司机失去工作又难以转岗，受影响家庭的收入和消费就会承压。改善低收入家庭的就业和公共服务条件，因此也是扩大需求的一部分。

## 4. 要把消费拉起来，作者主张先改哪里？

**先把基本公共服务补到农民工和低收入家庭身上。** 消费补贴能带动当期购买，教育、医疗、住房和养老则需要稳定的制度安排。作者建议中央更多承担基础养老、基础医疗保障和扩大义务教育范围等职责，地方负责保障性住房、教育培训等。比如，把滞销住房收购后转为保障房，面向进城务工家庭出租或出售。家庭能在城市安家，就会带动家具家电、子女教育和医疗养老等需求。社保更稳定，也能减轻家庭为防风险而攒钱的压力。

**提高农村养老金是一个较容易启动的切口。** 作者设想用部分刺激资金提高当期待遇，再探索划转国有金融资本，用收益持续补充养老资金。按书中的假设，向农村居民增加 **1万亿元** 收入，其中约 **8000亿元** 会直接转为消费，计入乘数效应后可拉动约 **1.2万亿元** 的GDP。这个测算说明了作者为什么把有限资金优先投向消费倾向较高的群体。

**再以城乡要素双向流动带动新一轮城镇化。** 作者把承接新增人口和产业的空间放在都市圈的中小城镇，并主张配套改革农村土地、财税和收入分配制度。他设想把城镇化率提高到 **75%以上**，同时缩小城乡公共服务差距，争取用十年左右把中等收入群体从 **4亿多扩大到8亿至9亿**。这条路径能否拉动消费，要看进城家庭能否稳定就业、举家定居，并获得相应的公共服务。

## 5. 扩消费、稳增长、稳预期最后怎么接到一起？

- **需求侧，让服务消费接力。** 房地产恢复到较低的正增长，教育、医疗、养老等服务消费成为新的需求来源。放宽服务业准入、扩大开放，让新增需求有足够的服务供给来承接。
- **要素侧，把更多公共资源投到人身上。** 财政支出更多用于教育、健康和社保，既能支撑当期消费，也能提高劳动者的技能和流动能力，为创新打基础。
- **产业侧，靠公平竞争稳定预期。** 长期、可信地保护各类产权，企业才更愿意投资和创新。在风险可控的条件下，也要让低效产能通过破产、兼并和重组等方式退出，为效率更高的企业腾出空间。

章末谈到改革怎么落地。顶层设计明确方向和底线，同时给地方和企业留出试验空间。这些改革共同指向增长方式的转型，从主要靠投资和出口拉动，逐步转向**创新提高生产率、消费支撑需求**。
