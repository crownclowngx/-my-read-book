# 《基层中国的运行逻辑》第二章：简书读后感编写计划

编写日期：2026-10-23。执行状态：已按单篇方案完成正文、三张自绘图与一张原书图，并在“基层中国的运行逻辑”文集保存为未发布草稿；重新加载后已核对标题与完整正文一致。结果见[目录与保存说明](00-目录与保存说明.md)。下文保留起草前的规划。

## 一、写作方案：一篇文章，沿原书四节推进

**建议合成一篇完整读后感，保留原书“城市等级—官员等级—晋升规律—重大政策出台”的顺序。**

这一章的四节有连续的解释关系：城市等级帮助观察行政资源的分配，官员等级说明组织中职位与权限的差异，晋升规律进一步解释人的激励，重大政策的两个案例再展示资源、权限与激励如何进入实际决策。合在一起，读者才能从静态的等级体系，读到动态的政策过程。

建议标题直接沿用原书：

**《基层中国的运行逻辑》第二章：等级制是行政资源分配的主要方式**

开篇承接第一章读后感：上一章讨论基层在怎样的组织架构中工作，这一章继续追问，在这样的架构中，资源如何分配，人如何获得激励，一项想法又如何变成政策。

正文可先按约6000～8000字起草，作为工作估计，不设置必须达到的字数。第二节以清楚解释概念为主，第三、第四节保留较充分的证据比较与案例分析；删减时优先去掉重复定义、过细的职位枚举和重复案例，不删掉论证条件与章节过渡。

本轮按单篇安排，不设连载编号。篇幅是否合适，以读者能否顺着四节完成一次理解为准。

## 二、如何延续第四、第五章的读后感模式

已对照《AI工程：大模型应用开发实战》第四章的“评估标准、模型选择、评估流水线”，以及第五章的“提示词简介、最佳实践、防御性提示工程”，并参考本书第一章已经完成的单篇文章和编写计划。

| 既有文章中的做法 | 第二章的具体安排 |
| --- | --- |
| 从一个具体问题进入概念 | 从“为什么同样叫区长、局长，所处层级和权限可能不同”进入等级问题 |
| 保留原书章节顺序，用自己的话解释 | 四节标题与内部主要分论题沿用原书，个人理解放在对应论述之后 |
| 案例随问题推进，有必要时回指前文 | 第一、第二节连用城市与职位的比较；第四节以西气东输和昆山两个原书案例集中收束 |
| 将陈述与支持它的证据对应起来 | 讲城市资源分配、官员晋升时，交代数据、研究对象、时期和结论范围 |
| 区分原书观点、补充资料和个人思考 | 使用“作者在本章提出”“这项研究发现”“我的理解是”等自然表达 |
| 图表负责解释关系，文字负责论证 | 城市等级保留原书图，职务职级与政策过程优先自绘，研究争议用短表格比较 |

沿用第四、第五章“具体问题—概念解释—案例或证据—个人理解”的写法。贯穿案例改用本书自己的城市、干部与项目，不强行把知识库助手或AI技术接进国家治理讨论。

第一人称主要表达认识如何变化，例如“过去我容易从称呼判断职位，读到这里才开始区分机构与个人”。书中调研、作者经历和文献发现均明确归于原书，不写成自己参与过的调研或项目。

开篇拟保留一段范围说明：本文对应原书第二章，按四节顺序展开；书中案例、个人理解与补充材料分别标明，图表说明来源与时间。

## 三、正文结构与各部分的写作任务

### 开篇：从“条块关系”走向“资源怎样分配”

先用一两段接回第一章：知道一个地方归谁管，还不足以说明它能获得多少资源，也不足以解释同样名称的职位为什么分量不同。

然后简述原书导言对价格机制与等级分配的区分。市场通过价格协调供求，组织内部还会通过制度、预算、职位与权限分配资源。这里讨论等级制的解释作用，不预先判断它在任何事务上都优于或劣于价格机制。

保留张五常关于资源分配方式的讨论作为作者引入问题的背景，篇幅不超过一小段。重点落到全文问题：**等级体系怎样影响资源分配，组织中的人如何行动，基层又怎样推动事情发生？**

### 第一节 中国城市的等级体系

**本节要回答：城市的行政位置，如何影响它获得资源和发展机会的条件？**

#### 一、波澜壮阔的城市化进程

先介绍原书给出的城镇化背景，再用第五部分资料A补充一个时间明确的新数据点。原书采用的人口普查数据与后续年度数据分别标注，不把新数据直接填进原书旧图。

这一小节的作用是提出问题：越来越多人口进入城市，城市之间的资源条件仍然存在差异。随后进入作者对城市等级的分析，不铺陈完整的城镇化发展史。

#### 二、中国城市的等级金字塔

按照原书依次说明直辖市、副省级市、普通省会城市、普通地级市，再说明县区与乡镇所在的基层位置。这里先把城市本身、主要领导和下辖单位分开，让第二节能够顺势解释官员级别。

主图使用原书图2-2，图注注明为原书2024年口径。说明图中主要是等级分类，并不表示前一类城市逐级管辖后一类城市；同样称为县、区或街道，也需要结合所在城市判断。

原书财政分配与大学分布两个例子都保留，但功能不同：财政例子解释资源经过哪些层次，大学分布说明公共资源在空间上的集中。书中“100亿元逐级分配”的叙述作为说明性例子介绍，不写成全国固定分成比例。

随后介绍原书引用的江艇等人的研究：行政级别、企业生产率与资源错配之间存在怎样的研究发现。正文优先讲清“获得更多资源”与“资源使用效率更高”需要分别判断。若采用书中百分比，必须同时注明研究时期、样本与测量方式；昆山升格后的测算属于研究推演，不能写成已经实施的升格结果。

个人理解落在：城市发展既要观察市场联系，也要观察行政资源的取得方式。等级能帮助解释一些差异，产业基础、区位、历史积累和地方行动仍需共同分析。昆山在后文的发展案例，正好能帮助读者理解这一点。

#### 三、行政区划变动的影响

沿原书“撤县设区—县改市—是否还会设立副省级市”的顺序，用三个短段解释：变动可能影响什么权限、资源与协调关系，为什么地方会关心这些变化。

这里将行政级别、行政隶属关系与经济管理权限分开。县改成县级市，并不自动意味着升到地级；国家中心城市等功能定位，也需与行政级别区别理解。原书关于政策趋势的判断按写作背景介绍。

本节末可用资料B补充一个问题：在城市发展更加重视存量质量的背景下，分析地方发展还需要看公共服务、产业与治理能力。用两三句即可，不另设城市更新专题。

**过渡：城市的行政位置会影响机构设置，而具体权力最终由机构中的人行使。下一节要进一步分清，机构、职位与个人之间是什么关系。**

### 第二节 中国官员的行政等级

**本节要回答：判断官员在组织中的位置，应该看哪些信息？**

先用简短文字交代原书的五个层次和正副职基准体系。然后沿作者列出的六项原则解释，每项保留一个最有说明力的例子，其余职位列举适当压缩。

| 原书顺序与表述 | 正文要讲清的内容 |
| --- | --- |
| 原则1：机构级别决定官员级别 | 先判断所在机构，再看所任职务；存在兼职时，要结合完整任职信息 |
| 原则2：副省级机构高出半级 | 按原书分别处理国家局、副省级城市与相关机关的特殊对应，逐项解释参照对象 |
| 原则3：党委高于政府 | 说明原书涉及的常委兼任、机构性质等具体情况，解释相应职位差异 |
| 原则4：干部高配只限主要领导 | 区分机构本身的级别与某个领导个人的配备情况 |
| 原则5：企事业单位参照政府部门 | 按隶属关系介绍书中例子；不同类别单位的管理制度需要分别理解 |
| 原则6：特殊情况特殊对待 | 简述助理、总师及括号标注等情形，重点教读者寻找完整依据 |

表格是起草提纲，正式稿仍按六个标题展开，避免把这一节写成职位名称速查表。国家局的比较基准与副省级市不同，图表中不要统一换算成一个无条件适用的“加半级”。

在作者讨论巡视员、调研员和主任科员的位置，增加一个简短概念说明框，依据资料D区分：

- **机构级别**：机构在组织体系中的位置。
- **领导职务及其层次**：担任什么领导岗位，履行哪些领导职责。
- **个人职级**：与领导职务并行的晋升序列，需要按相应规定理解。
- **实际职责与权限**：结合岗位分工、授权和具体制度判断。

书中有时用“级别”概括日常意义上的行政等级，正文保留其语境；涉及现行制度时，将职务、职级与级别等术语分开。通过这一补充，为下一节区分领导职务晋升、职级晋升、岗位交流与重用打下基础。

本节个人思考可以写成：过去容易从“处长”“主任”这样的称呼判断权力，读完后更愿意先问，这是什么机构、担任什么职务、负责什么事项。

**过渡：明确一个人处在什么位置之后，下一步才是理解他可能怎样流动，以及组织希望通过晋升激励什么行为。**

### 第三节 中国官员的晋升规律

**本节要回答：怎样从经验说法走向有条件、有证据的晋升机制分析？**

这一节是读后感的分析重点。保持原书三个分论题，让读者看到研究争议的推进过程。

#### 一、理解官员的晋升路径

沿原书四个观察展开：逐级晋升、晋升空间有限、起点与终点的区别、在党政与不同条线之间的履历变化。

重点解释金字塔结构下为什么高层岗位更少、履历为什么成为组织考察的信息来源。对原书关于“天花板”的经验描述，交代它所针对的职业路径，不把它改写成每个人必然停留的法定层级。

此处自然回指第二节：取得某个职级、担任某项领导职务与调到更重要的岗位，是需要分别观察的变化。这样能承接后面学者对“什么算晋升”的争议。

#### 二、十八大之前的官员晋升规律

按原书依次介绍政绩论、对政绩论的挑战、关系论及政绩与关系互补的解释。原书中的薄智跃、周黎安等人、兰德里及合作者、陶然等人、史宗瀚等人、贾瑞雪及合作者，分别归入对应的问题，不将文献写成作者名单。

可用一张三列短表辅助阅读：研究关注什么、使用什么样本、结论适用于什么范围。正式稿重点比较三个问题：

1. 研究的是省级、地市级还是更高层级的干部？
2. 经济表现影响晋升，还是晋升安排影响了官员被分配到什么地方？
3. 研究怎样定义晋升，是否包含职务层次不变的重用与交流？

保留原书日本通产省职位排序的例子，用一个短段解释“名称或层次相近，岗位的重要性仍可能不同”。原书表2-1可用于核对，不必再把整张表放入正式稿。

个人思考放在：面对“主要靠政绩”或“主要靠关系”的说法，先问研究对象、时期和证据。不同研究的结果可能与测量和样本有关，不能只选择符合自己印象的结论。这也延续第四章读后感中把判断落实到证据与适用条件的写法。

#### 三、十八大之后：新常态打破了旧规律

沿原书四个变化展开：政绩驱动与问责驱动的变化、选拔标准与年龄条件、政治忠诚的重要性、基层经历受到重视。先准确转述作者的分析，再补充个人理解。

这里重点讲清考核信息、监督方式与选拔标准怎样共同影响行为。作者讨论的是治理激励的变化，不能简化成某一个因素完全替代其他因素，也不能从文件要求直接推导所有地方的实际晋升结果。

随后以资料C的浙江差异化考核实践补充一段：当考核对象的岗位和地区条件不同，如何设计有区分的评价？将它放在原书“新变化”之后，作为观察当下制度实践的材料，不承担证明全国晋升因果关系的任务。

**过渡：个人行动受考核与晋升激励影响，但推动一个项目还要跨越部门和地区。理解了人的位置与激励，才能进入重大政策如何形成的问题。**

### 第四节 重大政策是如何出台的？

**本节要回答：基层的想法怎样取得支持，高层决策又怎样落实到具体地方？**

这是全文的案例重心。按照原书三个分论题展开，用前面三节的概念理解案例，减少新增抽象名词。

#### 一、国家层面的重大项目如何立项？

以原书西气东输案例为主，依据张国宝回忆录的书中转述，沿九个环节梳理：

基层单位有想法 → 向主管领导汇报 → 主管领导视察 → 向中央领导报告 → 中央领导批示 → 有关部委调研论证 → 中央开会审批 → 成立领导小组推进 → 项目实施。

流程旁说明三件事：基层提供问题与项目线索，上层协调重大资源，相关部委与地方在推进中表达诉求并协商。保留浙江与中石油的管网安排作为一个具体片段，帮助读者理解中央同意之后仍然需要协调利益与执行条件。

个人理解可以落在：一个想法成为项目，需要逐步取得证据、支持与实施条件。作者梳理的环节用于解释这一历史案例，图中明确写“依据原书案例整理”。

补充资料E只用于说明项目管理中存在不同制度路径。原书九步不改写成适用于所有投资项目、所有时期的统一审批程序。

#### 二、地方层面的重大创新何以成功？

以昆山自费开发区为第二个完整案例，保留原书“三板斧”的顺序与表述：“先做不说”“做了再说”“先上车，再买票”。

具体围绕三层问题解释：地方怎样利用横向合作扩大机会，怎样通过已经形成的实践取得关注，怎样最终获得正式认可。保留1981年横向合作、1985年工业新区、1988年专家与媒体推动、1992年获批等关键节点，避免展开成昆山发展全史。

这里回看第一节：行政位置影响资源条件，同时地方仍可能通过产业联系、组织行动和制度创新争取发展空间。昆山的案例能够说明这一机制，但不能单凭成功案例认定其他地方都具备相同条件。

原书这些做法发生在特定改革阶段。读后感重点提炼地方探索与上层认可的互动，讨论今天的创新时，应进一步观察正式试点、授权与制度承接等条件。

#### 三、专家学者在重大决策过程中起什么作用？

依次保留原书的三个作用：提供咨询、帮助论证；上报内参、获得批示；公开表态、形成舆论。用前面两个案例回指即可，不再增加第三个大案例。

西气东输输气容量的争论适合保留，帮助读者看到专家意见也会受到信息、预测和判断条件限制。专家提供的是知识与论证支持，最终决定还涉及资源、责任与利益协调。

本节结尾将前三节收回来：行政等级影响资源取得，机构与职务界定决策位置，考核与晋升影响行动动力，而政策落地需要这些条件在具体事项中相互配合。

### 篇末：我从这一章获得了什么观察方法

收束为两三段阅读认识，不再复述四节摘要。

拟形成的认识是：分析一个城市、一个职位或一项政策时，先辨认其组织位置，再问资源由谁配置、行为受到什么激励、推进需要谁参与。这是从本章提炼的观察方法，实际判断仍需具体材料。

最后选用原书第五道思考题中的高铁设站问题作为开放问题：如果想了解一座县城为何争取到高铁站，应当查找哪些规划、项目批复、地方材料和实施记录？读者可以据此练习分清愿望、决策过程与实际结果。正文只提出查证思路，不在没有材料时猜测当地决策内幕。

## 五、补充资料：放进相关小节，不另开“最新进展”章节

## 六、这篇文章应形成的个人思考

以下认识随正文逐步出现，篇末只保留最有帮助的两三点：

1. **看城市发展，需要同时看市场机会与行政资源。** 理解资源从哪里来之后，还要继续判断怎样使用、效果如何。
2. **看一个职位，需要区分名称、机构、个人与职责。** 行政等级是线索，具体事项的权限仍要看制度安排。
3. **看晋升规律，先问研究怎样提出和检验问题。** 不同层级、时期与测量方法会影响结论。
4. **看政策创新，要观察探索如何进入正式制度。** 地方信息、上层协调、专家论证与执行反馈共同构成值得查证的过程。

文章保留读后感的个人口吻，通过案例呈现认识变化，不将全章压成“等级决定一切”的单一判断。

## 七、起草、配图与交付顺序

1. 按四节及内部顺序起草一篇连续正文，先写清原书论证，再把个人思考放到对应段落。
2. 回查城市分类、职位示例、研究样本与两个项目案例。书中叙述与现行制度涉及不同时间时，明确分别表述。
3. 将资料A、B放入第一节，资料C放入第三节，资料D、E用于相应概念说明，控制补充材料的体量。
4. 制作三张自绘图并保留源码，核对一张原书图；根据文字需要调整图，而不是为了配图扩写正文。
5. 检查“相关关系—因果解释”“经验描述—制度规定”“案例流程—通用程序”等表述，确认结论与证据范围相符。
6. 通读四节之间的衔接，删去重复回顾；保留原书标题，使读者能够对照原章阅读。
